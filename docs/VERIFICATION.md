## 2. V2.0.0（基础功能）实测

- 四栏导航（首页 / 成绩 / 分析 / 设置）、深色模式切换
- 手动录入 643 分，实时总分；CSV、XLSX、PNG（相册）、PDF 四种来源导入并保存
- 中文成绩单 OCR：正确还原 10 列表格、匹配目标学生行、识别 125/135/130/88/92/90、总分 660，化学/地理按「赋分」表头识别
- 同名学生两条记录 → 提示「无法自动确定，请人工选择」并列出候选行（不自动猜）
- 备份 ZIP 导出 → 合并恢复：提示「跳过重复」，恢复后考试与成绩完好
- AI：本地 Mock OpenAI 服务验证连接测试（518 ms）、报告生成、Markdown 渲染、历史报告、复制、导出 PDF（有效 1 页 PDF）
- 真实 DeepSeek 端点使用错误 Key → 返回 401 并原样提示「密钥错误或无权限」，不会假装成功
- 横屏下总分曲线重新排版并可缩放
- 拍照入口：曾因清单声明 `CAMERA` 却未运行时授予而崩溃；改为走系统相机 `ACTION_IMAGE_CAPTURE` 不再声明该权限，并加异常兜底提示

- 录入联动：物理/化学显示「· 选考 / 已选考」并高亮描边，未选科目不高亮

- AI 联动：Mock 服务抓取真实请求体，提示词含「选科（3+1+2）：物理+生物+化学（首选：物理；再选：生物、化学）」「选考三科：物理、生物、化学」与「不得将未选科目作为当前选考科目」；快照含 `firstChoice / secondChoices / selectionCombo / electiveSubjects`，缺科时 `electiveTotal` 为 `null`

## 7. 尚未验证 / 已知限制

1. 仅在 Android 15（API 35）模拟器上验证，未覆盖 Android 13 / 14 真实机型差异（代码层面使用 API 33 起可用的接口，未使用 34+ 新 API）。
2. release 未开启 R8 混淆（避免 ML Kit / 图表库反射问题），因此包体未优化。
3. 手写体、强反光、低分辨率成绩单的 OCR 识别率有限，复核页会标红低置信度字段，需人工核对。
4. 未接入真实学校的赋分换算，选考总分只是 3 科之和，不代表任何省份投档规则。
