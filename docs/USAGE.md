# 得分追踪 · ScoreTrack 使用说明（V3.0.0）

## 一、安装

1. 将 `ScoreTrack.apk` 传到 Android 13 及以上手机。
2. 点击安装，若提示“未知来源”，在系统设置中允许该来源安装。
3. 首次启动无需注册登录，所有数据保存在本机。

命令行安装：`adb install -r ScoreTrack.apk`。

**从 V2 升级**：直接安装 V3 安装包即可（同签名，无需卸载），旧成绩、原始成绩单、AI 报告全部保留；首次启动会弹出「升级完成，数据已保留」并显示各表数量变化与自动备份目录。详见 [UPGRADE.md](UPGRADE.md)。

## 二、第一次使用

1. 首页点击「创建」→ 填写姓名、班级、学号 → 保存。多学生可随时在首页顶部切换（点学生名 → 选择或「管理学生档案」→ 右上「新建」）。
2. 点「录入成绩」手动录入一次考试，或点「导入成绩」用 OCR / 文件导入。
3. 录入后首页显示最近考试、总分、较上次变化、六科概览与总分小曲线。

> 同名学生请务必填写不同的班级或学号：系统不会自动合并同名档案，导入时若无法区分会要求你手动选择。

## 三、手动录入

成绩页 → 右下「录入成绩」：
- 选择学生、填写考试名称（可点常用名快捷填入）、选择日期、备注；
- 六科输入，赋分科目可另填原始分（可选）；
- 超出满分会标红并拒绝保存；六科未填完时显示“暂不计算”，**不会把缺考当 0 分**；
- 保存后可在列表中点开编辑或删除。

## 四、导入成绩（OCR / 文件）

首页「导入成绩」：

1. **选择来源**
   - 从相册选择（可多选多张图片）
   - 拍照识别（调用相机）
   - 从文件管理器导入（JPG/PNG/WEBP/PDF/XLSX/XLS/CSV）
2. **识别选项**（默认全开）：自动旋转/倾斜校正、图像增强（对比度、去噪）、透视矫正（表格边框）。
3. **识别结果**
   - 系统会先识别整张表格的所有学生行，再按当前学生的姓名/班级/学号定位目标行；
   - 若表格里有同名多人、找不到目标学生、表头无法确定、化学/地理赋分列不明确，会给出提示并要求人工选择或确认；
   - 每行显示语/数/英/物/化/地成绩，点「选这个」进入核对。
4. **核对页**
   - 展示原始成绩单预览、识别到的学生、考试名/日期/班级、六科成绩；
   - 每个科目下方显示“识别原文 + 置信度”，低置信度或超满分标红；
   - 任一科目右侧的刷新按钮可对该区域做**局部重新识别**；
   - 所有字段都能手动修改；「保存原始成绩单」开关决定是否把原图/PDF 存档（存档后可在考试详情里重新打开核对）。
5. 点「确认保存到成绩记录」才会写入数据库。

## 五、查看与分析

- **成绩页**：历次考试列表（按日期倒序），可编辑、删除、查看原始成绩单。
- **分析页**
  - 总分：总分曲线（可缩放拖动、点节点看考试详情）、总分平均/最高/最近变化、历次列表；
  - 六科：切换科目，切换“原始分 / 得分率”视图，显示当前、历史最高、平均、最近变化、六科得分率对比与趋势；
  - 综合统计：总分统计、六科明细、优势与薄弱科目、数据说明。
- 数据不足（例如只有一次考试）时只显示“数据不足”，不会编造趋势。

## 六、AI 成绩分析

1. 设置 →「AI 分析设置」：填 Base URL、API Key、Model（默认 DeepSeek 示例），可调 Temperature 与最大 Token →「保存配置」→「测试连接」确认可用。
2. 首页「AI 成绩分析」或分析页右上「AI 分析」→「生成 AI 分析报告」。
3. 首次会弹出隐私说明，确认后才会把结构化成绩发送到你配置的 API。
4. 报告生成后可：查看历史报告、复制文字、导出 PDF、删除、重新生成。
5. 未配置 API Key 时，其他功能不受影响。

详细配置见 [API.md](API.md)。

## 七、备份、恢复与导出

设置 →「数据备份与恢复」：
- **导出完整备份（ZIP）**：包含学生、考试、成绩、原始成绩单文件、AI 报告（不含 API Key）；
- **仅导出 JSON 数据**：纯数据备份；
- **导出 CSV 成绩表**：全部学生成绩，Excel 可直接打开；
- **导出当前学生成绩分析 PDF**；
- **恢复**：选择备份文件 → 显示版本/数量预览 → 选择「合并（推荐，按 ID 与内容指纹跳过重复）」或「清空并恢复」→ 开始恢复。恢复前会校验格式与版本，失败会给出原因且不改动现有数据。

## 八、选科管理（V4 新增）

新高考 3+1+2：首选 2 选 1（物理 / 历史），再选 4 选 2（生物 / 地理 / 政治 / 化学），组合共 12 种。

1. 入口：设置 →「选科管理」，或主页「选科概览」卡片。
2. 选择：点首选卡片选中（自动取消另一个）；点再选卡片，选满 2 门后其余置灰，需要先取消已选科目才能更换。
3. 结果：底部实时显示首选、再选一、再选二、完整组合与状态；未完成显示「还需选择 N 门」。
4. 保存：点「保存选科」写入数据库；「清空重选」会删除该学生的选科记录（不会删除任何历史成绩）。
5. 生效范围：
   - 选科按学生隔离，切换学生自动切换。
   - 主页「选科概览」显示当前组合，可点击修改。
   - 手动录入成绩页中，已选科目显示「· 选考 / 已选考」并高亮；生物 / 政治 / 历史在「选考科目（3+1+2）」区块录入。
   - 分析页六科筛选会对选考科目标注「· 选考」，对未选但有数据的科目标注「· 未选」。
   - AI 分析会把选科组合与选考三科作为分析重点发送给模型。
6. 统计口径：
   - 原有 **750 分总分**仍按语文、数学、英语、物理、化学、地理六科计算，不因选科改变。
   - 「选考成绩概览」按选考三科独立统计（满分 300），三科未齐时显示「暂不计算，不会按 0 分处理」。
   - 不同省份赋分规则通过扩展接口预留，默认直接使用录入分数。

## 九、主题、壁纸与目标卡（V3 新增）

### 8.1 更换主题颜色
1. 设置 →「个性化设置」。
2. 顶部选择 跟随系统 / 浅色 / 深色。
3. 在「预设主题」点任一色块（默认蓝、天空蓝、薄荷绿、樱花粉、薰衣草紫、日落橙、深海蓝），立即生效并保存。
4. 也可在「自定义颜色」输入 `#RRGGBB` 后点「应用自定义颜色」；点「恢复默认」回到默认蓝。
5. 底部导航、按钮、选中态、进度条、图表与强调文字会统一使用该主色；重启后保持。

### 8.2 设置主页壁纸
1. 个性化设置 →「壁纸」→「从相册选择壁纸」，选一张图片（自动复制到应用私有目录）。
2. 进入「壁纸编辑」：双指缩放（1×–4×）、单指拖动调整位置、下方滑块调整透明度（0%–100%）。
3. 点「保存」；编辑页显示的裁剪区域与主页完全一致，不会拉伸或留黑边。
4. 关闭「显示壁纸」开关或点「恢复默认背景」可移除；删除图片不影响任何成绩数据。

### 8.3 大学目标卡
1. 首页「大学目标」→「添加目标」（或 设置 →「大学目标」）。
2. 填写目标大学、目标专业（可选）、目标总分（1–750）→ 保存。
3. 主页卡片显示进度百分比（最近一次考试总分 ÷ 目标总分，可超过 100%）、最近总分/目标总分、进度条与「目标已达成」提示。
4. 卡片右上「✕」可关闭（仅隐藏，数据保留）；在「大学目标」页打开开关即可重新显示，⋮ 菜单支持编辑、上下排序、卡片颜色、透明度、隐藏剩余分数、删除。
5. 每个学生有各自的目标卡；没有完整成绩时显示提示，不伪造进度。
6. **校徽（V4.1 新增）**：编辑目标时点「选择」挑选校徽，或在「大学目标」页 ⋮ 菜单选「更换校徽」；校徽显示在卡片**左侧**，未设置时显示学校图标。图片会被压缩到长边 512px 并复制到应用私有目录，相册里删掉原图不影响显示；「移除校徽」只删图片，不删目标卡。

### 8.4 主页模块
个性化设置 →「主页模块」：大学目标 / 最近考试 / 六科概览 可开关与上下排序，关闭后主页立即移除该模块。

## 十一、常见问题

| 现象 | 处理 |
| --- | --- |
| 导入后没匹配到学生 | 确认姓名/学号与档案一致，或在识别结果里手动选择目标行 |
| 化学/地理提示“赋分列不明确” | 表格表头未标注赋分，核对页确认分数来源后手动确认 |
| 某科显示“缺失” | 该科未被识别，点该科右侧刷新做局部重识别，或手动输入（不会自动补 0） |
| AI 提示密钥错误 | 重新复制 API Key 并“测试连接”；确认 Base URL 与模型名匹配 |
| 打开原始成绩单提示文件不存在 | 原始文件已被删除或清理，成绩数据仍完整保留 |
| 升级后看不到目标卡 | 可能被关闭显示：设置 →「大学目标」重新打开开关，数据仍在 |
| 壁纸挡住文字 | 在壁纸编辑里降低透明度，或关闭「显示壁纸」 |
