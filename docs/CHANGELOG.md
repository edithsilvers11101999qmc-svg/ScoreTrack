# 更新日志

## V4.2.0（2026-11-29）

自定义考试倒计时。保留 V4.1.x 全部功能，数据库升级到 v5（仅新增一张表），覆盖安装即可升级，旧数据自动迁移。

### 新增

- **主页「考试倒计时」卡片（固定显示在大学目标卡之上）**
  - 显示考试名称、考试日期（设置了时间则同时显示时间）、剩余天数或当天剩余时分、备注；
  - 主显示标记；点击整卡进入「考试倒计时」管理页。
  - 没有任何有效考试时显示空状态「还没有添加考试」并提供添加入口。
- **考试倒计时管理页**
  - 支持添加多场考试：名称（必填）、日期（系统日期选择器）、时间（可选，系统时间选择器）、备注；
  - 支持编辑、删除（二次确认）、主页显示开关、设为主页主显示；
  - 列表按日期从近到远排序，过期考试自动归入「历史考试」，历史考试仍可编辑。
- **计算规则**
  - 按设备当前时区、自然日计算天数（`ChronoUnit.DAYS`），不使用固定秒数；
  - 当天且设置了时间时显示剩余小时/分钟；已到开考时间显示「考试正在进行」；
  - 考试当天不会提前归入历史，任何情况下都不出现负数；
  - 应用回到前台、定时刷新（30 秒）与重启后自动更新。
- **设置页新增「考试倒计时」入口。**

### 数据库

- Room `version = 5`，`MIGRATION_4_5` 新建 `countdown_exams` 表与 `index_countdown_exams_examDateEpochDay` 索引，不改动任何既有表。
- 备份格式 `version = 6`：新增 `countdowns` 字段；旧备份（v1–v5）无该字段，恢复后倒计时为空，其余数据不受影响。

### 测试

- 新增 `CountdownMathTest` 15 个用例（跨月、跨年、闰年 2 月 29 日、当天有/无时间、已开考、不足 1 分钟、已过期、自然日与时刻无关等）；单测合计 56 项全部通过。
- 模拟器覆盖安装 V4.1.1 → V4.2.0，弹窗显示「数据库版本 v4 → v5」，既有学生/考试/成绩/选科/目标卡/主题/壁纸/AI 报告全部保留；新增、编辑、删除、主显示切换、历史分组、重启保留均实测通过。

## V4.1.0（2026-11-20）

大学目标卡校徽。保留 V4.0.0 全部功能，数据库升级到 v4（仅新增一列），覆盖安装即可升级，旧数据自动迁移。

### 新增

- **目标卡校徽（位于卡片左侧）**
  - 编辑目标、或在管理页 ⋮ 菜单选择「更换校徽」，从相册挑选图片；校徽显示在卡片左方，未设置时回退为学校图标。
  - 图片复制到应用私有目录 `files/goal_logos/`，统一压缩到长边 512px、JPEG 90，不引用相册原图（相册删图不影响显示）。
  - 管理页每行也显示校徽缩略图；支持「移除校徽」，只删图片不删目标卡数据。
  - 切换/删除目标卡时自动清理不再使用的校徽文件，避免私有目录堆积。

### 数据库

- Room `version = 4`，`MIGRATION_3_4` 执行 `ALTER TABLE goal_cards ADD COLUMN logoPath TEXT`（可空，旧记录默认无校徽）。
- 备份格式 `version = 5`：`GoalDto` 新增 `logoBase64`，备份时把校徽内联为 Base64（>700KB 不写入）；恢复时写回私有目录并重建 `logoPath`。旧备份（v1–v4）无该字段，恢复后目标卡无校徽，其余数据不受影响。

### 兼容性

- 与 V4.0.0 同签名，支持直接覆盖安装；applicationId、数据库名与路径不变。

## V4.0.0（2026-11-20）

选科管理（新高考 3+1+2）版本。保留 V3 全部功能，数据库升级到 v3，覆盖安装即可升级，旧数据自动迁移。

### 新增

- **选科管理页面**
  - 首选科目 2 选 1（物理 / 历史），再选科目 4 选 2（生物 / 地理 / 政治 / 化学），共 12 种合法组合。
  - 实时结果预览：首选、再选一、再选二、完整组合（如「物理+生物+化学」）与完成状态。
  - 选满 2 门后未选项自动置灰，必须先取消才能更换；非法组合无法保存并给出具体原因。
  - 支持保存、修改、清空重选；清空不会删除任何历史成绩。
- **按学生隔离并持久化**
  - 新增 `subject_selections` 表（Room v3），每名学生一条记录，外键级联删除。
  - 切换学生自动切换选科；重启、冷启动后保留。
- **科目扩展**
  - 科目由 6 科扩展到 9 科：新增生物（赋分）、政治（赋分）、历史（原始分），满分均 100。
  - **原有 750 分总分规则不变**，仍按语数英物化地六科计算；选考总分作为独立统计（满分 300）。
  - 赋分规则预留 `ElectiveScoreRule` 扩展接口。
- **与成绩录入联动**
  - 手动录入页中已选科目标注「· 选考 / 已选考」并高亮描边；生物 / 政治 / 历史独立成「选考科目（3+1+2）」区块。
  - 分析页科目筛选标注「· 选考」「· 未选」，未选科目历史成绩仍可查看。
- **主页与设置**
  - 主页新增「选科概览」卡片：显示完整组合与三个选考标签，可点击进入修改；未完成时提示「尚未完成选科，点击设置」。
  - 选科卡片纳入主页模块配置，可开关、可排序。
  - 设置页新增「选科管理」，显示当前组合。
- **选考统计**
  - 选考科目逐科统计：当前、最高、平均、得分率、最近变化与独立曲线。
  - 选考总分曲线（满分 300）与最近 / 平均统计；三科未齐时明确提示不计算，不按 0 分处理。
- **AI 分析联动**
  - 提示词与快照新增选科组合、首选、再选、选考三科与最近选考总分。
  - 系统提示新增约束：必须围绕选考三科分析；不得凭选科推断大学录取资格。
- **备份与迁移**
  - 备份格式升级到 `version = 4`，新增 `selections` 字段；恢复兼容旧备份。
  - 数据库 v2 → v3 迁移（`MIGRATION_2_3`）：建表、补齐 3 门科目、插入选科概览模块；升级前自动备份、升级后校验，失败可从备份恢复。

## V3.0.0（2026-11-20）

主题、壁纸与目标管理版本。保留 V2 全部功能，数据库升级到 v2，覆盖安装即可升级，旧数据自动迁移。

### 新增

- **自定义主题颜色**
  - 默认蓝色，内置 7 个预设：默认蓝 `#2F5FA8`、天空蓝 `#2E8BC0`、薄荷绿 `#2E9E7E`、樱花粉 `#D96C93`、薰衣草紫 `#7A6BC8`、日落橙 `#E07A3F`、深海蓝 `#1B4F72`。
  - 支持自定义 HEX 颜色（`#RGB` / `#RRGGBB` / `#AARRGGBB`）。
  - 浅色与深色模式各自派生完整 Material 3 配色，切换立即生效并持久化。
  - 全局统一作用于底部导航、按钮、选中态、卡片、进度条、图表、强调文字。
- **主页壁纸**
  - 从相册选择图片，自动复制到应用私有目录（`files/wallpapers/`），原图删除不影响显示。
  - 支持双指缩放（1×–4×）、单指拖动、透明度 0–100%。
  - 编辑页与主页使用同一套变换逻辑，显示区域与裁剪一致，不拉伸、不留黑边。
  - 壁纸仅作用于主页，透明度只影响图片图层，文字与按钮始终清晰。
  - 可随时关闭、更换、恢复默认背景；删除图片不会影响任何成绩数据。
- **大学目标卡**
  - 字段：目标大学（必填）、目标专业（可选）、目标总分（1–750）。
  - 进度百分比 = 最近一次考试总分 ÷ 目标总分 × 100%，**不封顶**（超过 100% 显示真实值）。
  - 显示剩余分数 / 目标已达成、进度条、辅助信息开关。
  - 支持关闭（保留数据，可重新启用）、编辑、删除、上下排序、单独卡片颜色与透明度。
  - 目标按学生隔离，切换学生自动切换目标卡。
  - 没有完整成绩时显示「等待录入完整成绩」等提示，不伪造进度。
- **主页模块配置**：大学目标 / 最近考试 / 六科概览 可开关、可排序。
- **个性化设置页**：集中管理主题、壁纸、主页模块。
- **关于页**：软件名「得分追踪」、版本 V3.0.0、策划 Clara Windy、制作 deepseek，并提供更新日志入口。
- **数据库 v2 迁移**：新增 `theme_settings`、`wallpaper_settings`、`goal_cards`、`dashboard_cards` 四张表；升级前自动备份数据库与壁纸文件，升级后校验各表记录数，失败可从备份恢复。

### 优化

- 备份格式升级到 v3，包含主题、壁纸设置、目标卡与主页模块配置；旧备份（v1/v2）仍可恢复。
- 命中同名目标卡时主页显示「已隐藏 N 个目标卡（数据仍保留）」提示，避免误以为数据丢失。

### 兼容性

- `minSdk 33` / `targetSdk 35`，versionCode 3，versionName 3.0.0。
- 与 V2 使用同一签名证书（SHA-256 `70d42bef…12f7`），支持 `adb install -r` 覆盖升级，无需卸载。
